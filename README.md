# 🛡️ RKN Block Checker

Скрипт для массовой проверки доменов на наличие блокировки в реестре Роскомнадзора (РКН).  
Использует открытое API проекта [Роскомсвобода](https://reestr.rublacklist.net/), которое обновляется каждые 3 часа.

---

## 🔧 Возможности

- Загружает список заблокированных доменов из актуального API
- Сравнивает с вашим списком доменов
- Создаёт Excel-таблицу с результатами проверки

---

## 📦 Установка

1. Убедитесь, что установлен Python 3.6+
2. Установите зависимости:

---
pip install requests pandas openpyxl
## 📁 Подготовка
Создайте файл domains.txt в папке со скриптом
Добавьте в файл домены, например:
example.com	Нет
someblockedsite.ru	Да
vk.com	Нет

---
## ▶️ Запуск скрипта

python check_rkn.py
После выполнения появится файл проверка_ркн.xlsx с результатами:

Домен	Заблокирован в РКН
example.com	Нет
someblockedsite.ru	Да
vk.com	Нет
---
##🌐 Источник данных
Скрипт использует официальный открытый API Роскомсвободы:

https://reestr.rublacklist.net/api/v3/domains/
Обновляется каждые ~3 часа.
--- 
## ⚠️ Примечания
Проверяются только домены, не IP-адреса и не URL

Работает через интернет (требуется доступ к API)
